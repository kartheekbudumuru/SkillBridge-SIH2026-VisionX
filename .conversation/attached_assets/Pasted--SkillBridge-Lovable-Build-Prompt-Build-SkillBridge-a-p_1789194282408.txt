# SkillBridge — Lovable Build Prompt

Build **SkillBridge**, a premium AI-powered competency intelligence platform connecting Students, Universities, and Industry recruiters. This is a hackathon prototype (Smart India Hackathon 2026, Problem Statement 26044: "Portal for Academia–Industry Collaboration for Skill Mapping, Internships and Placement") by Team VisionX — it needs to look and feel like a real, deployable enterprise SaaS product, not a college project.

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Lucide icons
- Recharts for all charts/analytics
- Structure the app so Supabase can be connected later for auth, database, and storage — use clean service functions / data hooks instead of hardcoding data fetches directly into components, so Supabase can be swapped in without rewriting the UI.

## Design Direction
Premium, modern SaaS/AI dashboard aesthetic:
- Clean, professional, enterprise-grade, subtly futuristic — not gimmicky
- Rounded corners, soft shadows, subtle gradients, generous whitespace
- Strong visual hierarchy, modern card-based layouts
- Minimal, purposeful animations (not everything needs to move)
- Clean, readable charts
- Fully responsive: desktop, tablet, mobile

Avoid: neon colors, gaming aesthetics, generic templates, gradient overload, cluttered dashboards, fake "AI magic" gimmicks.

## Roles & Navigation
Build role-based routing/navigation for three roles:

**Student:** Dashboard · My Profile · Competency · Skill Gap · Learning Path · Opportunities · Applications

**University Admin:** Dashboard · Students · Skill Intelligence · Departments · Industry Demand · Training Recommendations

**Recruiter:** Dashboard · Post Opportunity · My Opportunities · Candidates · Shortlisted

Use a sidebar + top nav layout that adapts per role.

## Pages to Build

### Landing Page (public marketing page)
- Hero: "Bridge the Gap Between Talent and Opportunity." with subheading about connecting student competencies, university skill intelligence, and industry requirements.
- CTA buttons: "Explore Platform" and "View Demo"
- Visual flow diagram: Student Skills → Competency Intelligence → Skill Gap → Learning → Opportunity
- Sections: The Problem, How SkillBridge Works, For Students, For Universities, For Industry, AI-Powered Intelligence, Impact, Call to Action

### Student Experience
1. **Dashboard** — greeting, Career Readiness Score (e.g. 87/100), current skills, top skill gaps, recommended opportunities, learning progress, recent activity, a visual competency summary.
2. **Competency Profile** — skills grouped by category (Programming, Frontend, Backend, Database, Cloud/DevOps), each with a proficiency level (Expert/Advanced/Intermediate/Beginner) shown via progress bars or radial charts.
3. **Skill Gap Analysis** — student selects a target role (e.g. "Full Stack Developer"); show a side-by-side "Your Skills vs Industry Requirements" bar comparison with status icons (✓ met, ⚠ partial, ✕ gap), an overall Career Readiness % and Skill Gap %, and a short natural-language insight summarizing strengths and focus areas.
4. **Personalized Learning Path** — a visual roadmap generated from skill gaps, each item showing current %, target %, and estimated days, with a Learn → Practice → Assess → Complete progress stage per item.
5. **Opportunities** — list of internship/job cards showing title, company, location, type, required skills with match indicators, overall match %, eligibility, deadline, and View Details / Apply buttons.
6. **Opportunity Details** — full job details plus a "Why this match?" breakdown showing a factor-by-factor score contribution (e.g. skill matches adding points, missing skills subtracting points) building to the final match %, visualized clearly (e.g. a stacked/waterfall-style bar).
7. **Applications** — a Kanban/timeline view of application pipeline stages: Applied → Under Review → Shortlisted → Interview → Selected.

### University Admin Experience
1. **Dashboard** — KPI cards (Total Students, Students Analysed, Job Ready, Students With Skill Gaps, Industry Partners) plus charts for most common skills, most common skill gaps, department readiness, industry demand, and placement/internship trends.
2. **Student Skill Intelligence** — aggregate view of student skill data across the university.
3. **Department Analytics** — readiness and gap breakdowns per department.
4. **Industry Demand** — demand vs. supply comparison per skill (e.g. Java, React, AWS, Docker) with high-priority gaps highlighted.
5. **Training Recommendations** — most common skill gaps as a ranked bar list, plus actionable insight + recommendation cards (e.g. "42% of CSE students lack cloud deployment skills → Launch AWS + Docker training program").

### Recruiter Experience
1. **Dashboard** — overview of posted jobs, applicants, shortlisted candidates.
2. **Create Job** — form with job title, company, description, location, employment type, required skills, preferred skills, minimum CGPA, eligible branches, experience; "Publish Opportunity" button.
3. **Job Management** — list/manage posted opportunities.
4. **Candidate Recommendations** — AI-ranked candidate list with match %, top skills, skill gaps, projects, CGPA, experience; View Profile / Shortlist buttons.
5. **Candidate Profile** — full candidate overview, competency score, technical skills, projects, certifications, education, career readiness, skill gaps, and an explainable match-score section.

## Reusable Components
Build these as shared components used consistently across all pages: KPI cards, skill badges, progress bars, match-score visual, charts, opportunity cards, candidate cards, skill-gap cards, roadmap/timeline component, data tables, sidebar, top navigation.

## Demo Data (seed realistic data, no lorem ipsum)
- 20+ students with realistic Indian names, branches, and skill sets
- 10 fictional companies
- 20 jobs/internships across those companies
- Multiple skills across categories (Programming, Frontend, Backend, Database, Cloud/DevOps, etc.)
- Multiple departments (CSE, ECE, Mechanical, etc.)
- Sample applications in various pipeline stages
- Sample learning paths tied to skill gaps

## Matching & Scoring Logic (simulated for prototype)
Implement a deterministic, modular weighted scoring function — no fake API calls:
- Skill Match: 60%
- Projects: 15%
- Education: 10%
- Experience: 10%
- Other: 5%

Write this as a clean, isolated utility/service function (e.g. `calculateMatchScore()`) so it can later be swapped for a real ML/embeddings-based service without touching the UI. Use it to power both the opportunity match % and the "Why this match?" explainability breakdown.

## UX Requirements
Every major page needs: loading state, empty state, error state, hover states, responsive layout, toast notifications where relevant, and clear CTAs. Keep animations purposeful and minimal, not decorative on every element.

## Priority Demo Flow (must be the most polished path — should run in 3–5 minutes)
Student Login → Dashboard → Competency Profile → Select Target Role → Skill Gap Analysis → Personalized Learning Path → Recommended Opportunity → Why This Match? → Apply

Then: University Dashboard → University Skill Gaps → Industry Demand → Recommended Training Action

Then: Recruiter → Create Job → AI Candidate Ranking → Candidate Profile → Shortlist

## Build Order
1. Landing page + role-based auth/navigation shell
2. Student flow end-to-end (this is the primary demo path — prioritize polish here)
3. University admin flow
4. Recruiter flow
5. Shared component polish, responsive pass, empty/loading/error states

Do not attempt every backend/AI feature before the frontend experience is usable — get the full click-through demo working with realistic seed data first.
